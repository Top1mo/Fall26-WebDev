# Fall26-WebDev

CSE343 Web Development course repository containing laboratory tasks and assignments.

## Labs Overview

### [Lab 2: HTML & CSS](Lab%202/Html%20Lab%20task/firstHTML.html)
- **Task:** Student Portfolio Webpage (`firstHTML.html`, `style.css`)
- **Key Concepts:** Semantic HTML5 elements (`<header>`, `<main>`, `<section>`, `<article>`, `<address>`, `<footer>`), modern responsive CSS styling, card layouts.

### [Lab 3: JavaScript & DOM Manipulation](Lab%203/Calculator%20Lab%20task/index.html)
- **Task:** Interactive iOS Calculator (`index.html`, `style.css`, `script.js`)
- **Key Concepts:**
  - **DOM Selection:** Selecting nodes via `getElementById` and `querySelector`.
  - **Event Handling:** Event delegation on the keypad parent container with `addEventListener`, event object properties (`e.target`, `dataset`).
  - **Logic & Functions:** Pure arithmetic computation functions, floating point precision handling, dynamic font sizing, keyboard shortcuts support.
  - **Styling:** Pixel-accurate iOS dark theme calculator with authentic button states and animations.

### [Lab 4: Advanced JavaScript & TypeScript](Lab%204/Todo%20App%20Lab%20task/index.html)
- **Task:** TypeScript Todo Application (`index.html`, `style.css`, `app.ts`, `app.js`)
- **Key Concepts:**
  - **TypeScript & Transpilation:** Configured via `tsconfig.json` (ES2020 target, strict mode), compiled with `tsc`.
  - **ES6 Classes & OOP:** `TodoItem` and `TodoApp` classes with private fields, constructors, getters, and setters.
  - **Array Methods:** Declarative transformations using `.filter()`, `.map()`, and array manipulation.
  - **Modern ES6 Syntax:** Destructuring assignments, spread/rest operators (`...`), arrow functions, template literals.
  - **Features:** Add todo, filter (All / Active / Completed), double-click to inline edit (Enter to save, Escape to cancel), toggle status, delete, clear completed, clear all, and `localStorage` persistence.
